# UN Responsible Consumption & Production — JavaScript Group Project
An interactive web page about the UN's Responsible Consumption & Production goal. Users can browse a table of examples, search, sort and filter them, add new examples, and manage tags. Built by a team of three as a Year 1 JavaScript group project at Dundalk Institute of Technology (DkIT), BSc (Hons) in Computing in Software Development.

## Features

- **Search** examples by title as you type
- **Sort** the table
- **Filter** the examples
- **Add a new example** through a form (target, title, rating from 1 to 5, description, image URL and up to four tags)
- **Tag Manager** for managing tags
- **Pop-up (modal) windows** for forms and details
- **Responsive layout** with a hamburger menu for small screens (`mobile.css`)

## Tech stack

- **HTML5** for page structure
- **CSS3**: `main.css` (layout), `table.css` (table styling), `mobile.css` (small-screen layout)
- **JavaScript** in `JSFiles/main.js` for the interactive features
- **Git / GitHub** for version control and team collaboration

## Run locally

1. Clone the repository:
   ```
   git clone https://github.com/GaryChew0717/JavaScript-Group-Project---Y1.git
   ```
2. Open `index.html` in a web browser.
3. If the page appears empty because the browser blocks local files, run it through a local server instead, for example the **Live Server** extension in VS Code.
